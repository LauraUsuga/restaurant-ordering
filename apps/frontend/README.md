# Frontend - Restaurant Ordering

## Stack

- React
- TypeScript
- Vite
- Material UI

---

## Pages

- `/` → Menu
- `/cart` → Cart + checkout
- `/orders/:orderId` → Order status + timeline

---

## Run

```bash
npm install
npm run dev
```

---

## Features

- Menu listing
- Add to cart
- Cart pricing display
- Checkout flow
- Order timeline visualization
